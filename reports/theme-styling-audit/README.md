## 🚀 Implementation Steps

### Quick Start (3 Steps)

**1. Import CSS**
```css
/* In /styles/globals.css */
@import './themes/dark.css';
@import './themes/dark-extended.css';
```

**2. Activate Theme**
```html
<!-- Add .dark class -->
<html class="dark">
```

**3. Use BEM Classes**
```html
<button class="button button--primary">Click Me</button>
```

## 🐛 Troubleshooting

### Common Issues

**Dark mode not applying?**
- ✅ Verify `.dark` class on `<html>` or `<body>`
- ✅ Check CSS import order in globals.css
- ✅ Clear browser cache

**Components not styled?**
- ✅ Verify exact BEM class names
- ✅ Ensure dark-extended.css imported
- ✅ Check for CSS specificity conflicts

**Accessibility issues?**
- ✅ Run Lighthouse audit
- ✅ Test keyboard navigation
- ✅ Verify contrast ratios

See full troubleshooting guide in `/docs/dark-mode-usage-guide.md`.
