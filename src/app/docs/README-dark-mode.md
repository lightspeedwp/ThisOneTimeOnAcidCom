## 🚀 Quick Start

**New to the dark mode theme? Start here:**

1. **Read:** [Quick Reference Card](/docs/dark-mode-quick-reference.md) (5 min)
2. **Review:** [Usage Guide](/docs/dark-mode-usage-guide.md) (15 min)
3. **Implement:** Follow the 3-step setup
4. **Deploy:** Use [Implementation Checklist](/tasks/dark-mode-implementation-checklist.md)

**3-Step Setup:**
```css
/* 1. Import theme files */
@import './themes/dark.css';
@import './themes/dark-extended.css';
```

```html
<!-- 2. Add dark class -->
<html class="dark">
```

```html
<!-- 3. Use BEM classes -->
<button class="button button--primary">Click Me</button>
```

## 🐛 Common Questions

### How do I activate dark mode?
Add `.dark` class to `<html>` or `<body>` element. See [Quick Start](#quick-start).

### Can I customize the colors?
Yes! See [Customization Guide](/docs/dark-mode-customization-guide.md).
