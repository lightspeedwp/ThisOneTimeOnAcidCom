## Content Model Taxonomy

### Categories

- **Portfolio** - Project showcases
- **Blog** - Journal entries and articles
- **Events** - Festival and event coverage
- **Resources** - Educational content
- **About** - Biographical and company info

---

## Metadata Structure

- Title, Slug, Description
- Category, Tags
- Author, Date, Update Date
- Featured Image
- Status (Draft, Published, Archived)

---

## Categorization System

Content tagged with multiple tags for filtering and discovery.

**Tag Examples:**
- Festival (Koh Phangan, Ibiza, etc.)
- Technique (Makeup, Hair, etc.)
- Medium (Photos, Video, Article)
