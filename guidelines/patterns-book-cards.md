## Card Variations

### Standard Card
- Image, title, description
- Hover effect (scale, shadow)
- Click to detail page

### Featured Card
- Larger, prominent display
- Badge or label
- Additional metadata

### Grid Card
- Compact version
- Multiple per row
- Responsive sizing
