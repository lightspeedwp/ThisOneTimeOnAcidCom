## Performance Targets

- **Largest Contentful Paint (LCP):** < 2.5s
- **Interaction to Next Paint (INP):** ≤ 200 ms
- **Cumulative Layout Shift (CLS):** < 0.1
- **Page Load:** < 3s (3G)

---

## Optimization Checklist

- [ ] Images lazy-loaded
- [ ] CSS/JS minified
- [ ] Code splitting applied
- [ ] Caching configured
- [ ] Bundle size monitored
