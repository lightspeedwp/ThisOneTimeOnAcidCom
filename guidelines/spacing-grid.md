## Spacing Scale

8px base unit progression:

| Scale | Value | Example |
|-------|-------|---------|
| xs | 4px | Icon padding |
| sm | 8px | Compact spacing |
| md | 16px | Default spacing |

| xl | 32px | Large sections |

## Grid System

- Base unit: 8px
- Gutter: 16px–24px (responsive)
- Max width: 1200px (content container)
