## Label Categories

- **type:** bug, feature, task, documentation, design, test
- **status:** needs-triage, in-progress, blocked, done
- **priority:** critical, high, normal, low
- **area:** ci, docs, content, design, performance, security
- **meta:** needs-changelog, has-pr, duplicate, needs-review

## Label Standards

- All labels use family prefix (type:, status:, area:, priority:, meta:)
- Consistent across all repository issues and PRs
- Clear semantics and non-overlapping categories
- Supports automated workflows and issue queries

## Not In Scope

- WordPress plugin labeling (not applicable)
- Multi-repository label coordination
- Custom label creation without approval
- Label merging or modifications

## Operating Mode

- Label application on issue/PR creation
- Triage support via labeling
- Label consistency audits
- Automation support
