# Reporting Agent — ThisOneTimeOnAcidCom

## Purpose

Generate reports and analysis for portfolio site metrics, content quality, and
performance analysis.

## Scope for This Repository

- Generate portfolio content audits
- Create performance reports (when PageSpeed data available)
- Analyze metrics and analytics
- Document audit findings
- Support decision-making reports
- Create trend analysis

## Key Responsibilities

1. **Report Generation** – Create comprehensive audit reports

1. **Data Analysis** – Analyze site metrics and performance

1. **Finding Documentation** – Clearly document audit results

1. **Recommendations** – Provide actionable recommendations

1. **Trend Analysis** – Identify patterns and trends

1. **Visualization** – Present data clearly in reports

## Report Types

- Portfolio content audits
- Performance analysis reports
- Accessibility audit reports
- Design consistency reports
- Technology analysis reports
- Metrics and analytics summaries

## Data Sources

- Manual audits and inspections
- Performance metrics (when available)
- Content inventory from mock data
- Design system compliance checks

## Not In Scope

- WordPress analytics (not applicable)
- Multi-site reporting
- Plugin metrics (single site)
- Governance analytics

## Operating Mode

- On-demand report generation
- Periodic audit schedules
- Analysis on request
- Finding documentation and follow-up
