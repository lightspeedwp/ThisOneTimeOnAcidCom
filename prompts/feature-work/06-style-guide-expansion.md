Assess current style-guide coverage relevant to the book site without resuming unrelated held feature work.

Read current evidence before following historical path examples. This is a React/TypeScript/Vite book website, not a WordPress runtime or makeup-portfolio rebuild. Retain sourced memoir material without restoring its former page architecture.

## 3. Audit steps

1. Inventory current style-guide sections, tabs, element examples, component states and data sources; compare actual rendering/requirements rather than assuming an incomplete legacy version.

2. Assess typography, colours, spacing, buttons/links, forms, navigation, cards, FAQ/accordion and rich-text examples where present. Resolve raw value versus token usage against documented exceptions and current two-font direction.

3. Check both themes, responsive states, keyboard/focus, semantic labels, contrast, reduced motion and long/empty/error examples. Record static versus observed checks and missing environments.

4. Preserve the separate page-layout browser request in content-specimens/03-page-layout-browser.md as held. Do not silently cancel it, create a new dev-tools route or claim all old feature work complete.

5. Return precise coverage gaps and supported example proposals for review, including dependencies and unresolved design decisions. No component, route, content, CSS, task or guideline edits.
