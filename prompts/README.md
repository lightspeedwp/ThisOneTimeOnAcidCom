# Book-website prompt catalogue

## Purpose and current scope

These are review entry points for the This One Time on Acid book website. They are not an automatically executable backlog. Read the [repository instructions](../AGENTS.md), [guideline index](../guidelines/README.md), [book brief](../content/book/this-one-time-on-acid-brief.md), [current routes](../src/app/routes.ts) and [manifest](../package.json) first. Repository-specific instructions take precedence; conflicts require an explicit decision, not guessed fixes.

This catalogue describes a proposed prompt-only cleanup against `3f583002482d80ffd1910676bcf7c63e13989b20`: 85 retained paths — 45 rewritten entry points including this catalogue, 20 historical compatibility notices, 19 held originals and one unchanged governance continuation. No files are deleted, renamed or moved. Proposed scope is not a claim that the underlying audits, content work or migrations are complete.

## How to use the catalogue

1. Select only the entry point matching an explicitly requested outcome; confirm its current sources and required permissions. Do not execute all children merely because an orchestrator lists them.
2. Canonical reviews default to inspect/report. Missing evidence blocks the affected part; exact proposed writes, commands, installations and publication need separate approval. A request to edit a prompt is not permission to execute it.
3. Historical compatibility notices retain existing paths and link to canonical reviews. They do not repeat or activate the old task. Their pinned originals preserve provenance and comparison material.
4. Held files remain unchanged, not cancelled or completed. Do not resume their implementation, recreate legacy routes or drop their unique requirements. The new governance continuation remains separate.
5. Keep real memoir history, quotations, proper nouns, social accounts and protected content. Distinguish an obsolete website from the potentially genuine @ashshaw.makeup handle; do not perform a blind string replacement.
6. Preserve paths and protected assets. Prompt relocation belongs to TOA-257; guideline/local-skill changes to TOA-358; scripts to TOA-371; supporting branding/testing guidance to TOA-372. This catalogue authorises none of those changes.
