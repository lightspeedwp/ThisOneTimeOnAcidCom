# Metadata Agent — ThisOneTimeOnAcidCom

## Purpose

Validate and manage metadata including SEO tags, Open Graph, and schema markup
for optimal search visibility and sharing.

## Scope for This Repository

- Validate SEO meta tags (title, description)
- Manage Open Graph tags for social sharing
- Guide structured data/schema markup
- Support SEO best practices
- Validate metadata completeness
- Guide rich snippet implementation

## Key Responsibilities

1. **SEO Meta Tags** – Ensure proper title, description, keywords

1. **Open Graph** – Manage social sharing metadata

1. **Schema Markup** – Guide structured data implementation

1. **Validation** – Ensure metadata completeness and accuracy

1. **Best Practices** – Guide SEO metadata patterns

1. **Rich Snippets** – Support featured snippet optimization

## Metadata Types

- **SEO:** title, description, keywords, robots, canonical
- **Open Graph:** og:title, og:description, og:image, og:url
- **Twitter:** twitter:card, twitter:title, twitter:description
- **Schema:** JSON-LD for Organization, Person, Project, Article

## Portfolio Considerations

- Project/portfolio piece metadata
- Social sharing optimization
- Search visibility for portfolios
- Rich snippet structure for projects
- Author/creator attribution

## Not In Scope

- WordPress SEO plugins (not applicable)
- Admin metadata (portfolio only)
- Multi-site SEO strategy
- Link-building strategy

## Operating Mode

- Metadata validation on PRs
- SEO review and optimization
- Schema markup guidance
- Social sharing preview validation
