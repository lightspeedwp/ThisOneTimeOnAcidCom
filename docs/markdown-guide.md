1. Basic Text Formatting
Heading 1 to 6: Use # followed by a space. The number of # symbols indicates the level.
# Heading 1
## Heading 2
Bold: Wrap text in ** or __.
**bold text**
Italic: Wrap text in * or _.
*italicized text*
Bold & Italic: Wrap text in *** or ___.
***bold and italic***
Strikethrough: Wrap text in ~~.
~~strikethrough~~

2. Lists & Organization
Unordered List: Start lines with -, *, or + followed by a space.
Ordered List: Start lines with a number followed by a period (e.g., 1. ).
Task List (Checkboxes): Use - [ ] for unchecked and - [x] for checked items.
Nested List: Indent the sub-list item by two or four spaces.
Horizontal Rule: Use three or more ***, ---, or ___ on a single line.

3. Links & Media
Inline Link: [Link Text](https://url.com).
Reference Link: [Link Text][ID] then define it elsewhere as [ID]: https://url.com.
Image: ![Alt Text](image-url.jpg).
Automatic Link: Enclose a URL in angle brackets <https://url.com>.

6. Advanced Formatting
Footnotes: Use [^1] in text and [^1]: My footnote at the bottom.
Superscript: X^2^ or X^2 (depending on the renderer).
Subscript: H~2~O or H~2.
Highlight: Enclose text in ==.
==highlighted text==
Definition List: Term on one line, followed by : definition on the next.
Escaping Characters: Use a backslash \\ before a special character (e.g., \\*) to display it literally.
