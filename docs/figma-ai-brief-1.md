# Figma Make AI Brief + Content
## Project: *This one time on acid...*

## 1. Project summary
Build a responsive, multi-page book website for **This one time on acid...**, the first book by **Ash Shaw**.

This is **not** a portfolio site and **not** a generic author site.
It is a **book-first website** built around one flagship project.

The book is a:
- **hybrid memoir**
- **creative-life guide**
- **cult, artistic, psychedelic, emotionally vivid project**
- site that captures emails before the visitor can read the rough draft

The site must feel like:
- a cult book landing page
- an editorial memoir site
- a neon-lit underground cultural artefact
- a high-conviction author platform for one specific title

It must not feel like:
- a beauty services site
- a makeup portfolio site
- a corporate self-help site
- a rave flyer with no editorial clarity
- a generic blog theme

## 2. Core business goals
Primary goals in order:
1. **Email signups to unlock the rough draft**
2. **Credibility-building for readers, publishers, media, and event organisers**
3. **Future pre-orders for the final book and later print edition**
4. **Support speaking, workshops, event appearances, and media opportunities**

## 3. Core questions the website must answer within the first screen or two
The design and copy must make these clear immediately:
1. What is the book?
2. Who is it for?
3. Why should they care?
4. Why is Ash the right person to write it?
5. What should the visitor do next?

## 5. Brand and visual direction
### Emotional tone
- cult
- artistic
- intimate
- vivid
- raw
- strange in a confident way
- creative
- emotionally direct
- editorial
- high-energy but not chaotic

### Visual references
Think:
- 80s / 90s psychedelic print culture
- neon poster energy
- underground editorial magazine
- blacklight atmosphere
- dark-room glow
- cult memoir cover design

### Colour system
Primary background:
- Atomic black / near-black: `#0B0B10`

Surface colours:
- Dark charcoal: `#12121A`
- Slightly raised dark panel: `#171722`

Primary brand colour:
- Neon pink: `#FF3AAE`

Secondary accent:
- Neon yellow: `#F4FF3C`

Supporting accent (use sparingly):
- UV violet: `#8A63FF`

Text colours:
- Warm off-white: `#F6F2EB`
- Muted copy: `#CFC7BB`
- Fine print: `#9C9488`

Rules:
- body text must not be set in neon pink or neon yellow
- neon colours are for accents, buttons, links, highlights, key labels, and glow effects
- keep contrast high and legible

### Typography
Use a maximum of two font families.

Recommended pairing:
- **Headings / display:** Space Grotesk or similar modern geometric grotesk with punch and personality
- **Body / UI:** Inter or similar highly readable sans-serif

Display styling:
- large headings
- some all-caps usage
- slightly expanded tracking for hero and nav
- strong typographic hierarchy

Body styling:
- readable
- editorial
- medium line length
- generous line height

### Texture and effects
Use subtle:
- grain
- glow
- blurred neon orbs
- soft gradients
- edge lighting

Avoid:
- heavy particle effects
- flashing animation
- illegible liquid type
- too many overlapping gradients
- visual noise that weakens conversion

## 6. UX principles
- book-first, not personality-first
- high emotional clarity
- strong hierarchy
- large, confident typography
- generous spacing
- clear CTA repetition
- minimal top-level choices
- every page should support the draft signup funnel
- use layered storytelling, not clutter
- build for mobile first, then expand elegantly

*This one time on acid...* is a hybrid memoir and creative-life guide that traces Ash Shaw’s journey across childhood difference, dancefloors, festivals, entrepreneurship, movement, travel, Berlin nights, UV paint, and the slow cumulative effect of a life lived in full colour.

Part memoir, part philosophical field guide, the book asks what it means to build a life that feels vivid, honest, and self-authored. It explores neurodivergence, belonging, costume, community, risk, discipline, visibility, and the strange alchemy through which identity becomes art.

## 30. Follow-up prompts for iteration inside Figma Make
### Follow-up prompt 1 — make it more book-first
Reduce any sense that this is a personal portfolio. Increase the prominence of the book cover, book headline, email capture, and the “What this book is” section. Make the homepage feel more like a cult book launch site and less like a creator homepage.

### Follow-up prompt 2 — sharpen the art direction
Push the visual language further toward 80s/90s psychedelic editorial design. Add more contrast, more dark atmosphere, more controlled neon glow, and stronger typographic confidence. Keep it premium and readable.

### Follow-up prompt 3 — improve the conversion funnel
Make the email capture more persuasive. Increase the visibility of the hero signup form, improve the draft teaser block, and repeat the primary CTA more clearly through the homepage and Read the Draft page.

### Follow-up prompt 4 — make it easier to map to WordPress
Simplify anything too app-like or overly custom. Use reusable sections and patterns that can translate easily to WordPress blocks and templates.
